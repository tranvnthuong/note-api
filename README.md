##### NoteApp Express.js (March - April 7, 2025)
Backend using NodeJS (Express) for Note application integrating marketing advertising system.
Personal project completed in 5 weeks, focusing on learning and applying Express.js, JWT, MongoDB, and practical deployment on AWS.
##### Features
- Endpoint stores note data
- Query note data by :slug
- Endpoint to create account, login to Affiliate dashboard
- Authentication with JWT
##### Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- Database: MongoDB
- Authentication: JWT
- Hosting: AWS / Vercel / Heroku
##### Experience
- Understand and implement MVC model in Node.js
- Work with REST API (GET, POST, PUT, DELETE)
- Optimize API performance with caching and pagination
- Manage session and login token (JWT)
- Deploy application to AWS and configure private domain with Nginx
